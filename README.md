# Week-7-Move-Your-Way
 
Plan It:

What is the goal of this website?

Make a website for promoting Nike and their shoes. Make Nike for everyone. Anyone can use.

Who are you building for, and what do they care about?

People who are not currently fans of Nike, but might want to be.

Describe how users should use the website from the moment they visit it. What should they see first, what should they click, and what should happen next?

Include a label and design for each shoe. Put a link to the online store.

What is the one big idea Move Your Way should communicate?

Nike is for everyone.

There should be a ton of activities to choose from. What are some categories of activities that you would want in there?

Hiking, biking, walking.

How should the site present itself to non-sporty kids to get their attention and get them motivated?

Nike shoes being used in non-sporty contexts.

Test It:

Change the shoes. Make them look real. Change the slogan from "Sport is for Everybody" to something more interesting.

Expand It:

Make a tag for each shoe. Add the ability to search by tag. Put this function in the bottom right as a circle icon. It becomes a search bar when clicked on. The search bar is at the top, where the user can search by shoe. Search by tag is below it.
